# 随想

「随想」保存零碎的感受与念头。入口位于左侧「Metis 总控」下方，属于当前实例的所有者，不依附某个项目或对话。

## 记录与回顾

- 打开「随想」，直接写正文，点击「记下来」或按 Command/Ctrl + Enter。无需标题和分类。
- 记录按创建时间倒序展示，时间按浏览器本地时区显示。可以按正文关键词搜索，每页 20 条。
- 点击日期可打开单条记录的链接；编辑不改变原始创建时间，并显示「已编辑」。
- 可编辑、删除记录。编辑期间保留草稿；离开页面有未保存内容时会提示。刷新或关闭后不保证保留未保存草稿。
- 两个窗口同时编辑时，服务端拒绝旧版本覆盖。保留草稿供复制，取消编辑并核对最新原文后再修改。
- 页面在前台每 10 秒重新读取记录，也在重新聚焦时刷新，因此可看到助手和其他窗口保存的随想。

你也可以在能使用 Metis Gateway 工具的对话中说：

> 帮我记一下：今天走路回家时，突然觉得慢一点也挺好。
>
> 最近关于工作的感触有哪些？
>
> 看看我上周记下的想法，帮我回顾一下。

助手使用同一存储，代记时保留原话，只有用户要求整理时才改写。创建记录自动标记「由 Metis 代记」，并保存来源会话与轮次；已有记录的创建来源不随编辑改变。原会话仍存在时，页面提供「来源对话」入口。回顾应引用记录日期和单条记录链接，区分原话与助手理解，不虚构未记录的感受。

## 与长期记忆的关系

随想独立于 [长期记忆](memory.md)：随想表达当时的体验，长期记忆记录稳定偏好和事实。随想正文不会进入每轮或每个新会话的记忆索引。助手按请求查询，也不应自动收集普通聊天内容或把短暂情绪固化成人格判断。

实例总控的自动记忆整理不能调用随想工具。此规则约束 Gateway，不是对具有本机文件权限的 Provider 的独立沙箱。不同 Provider 只有接入本实例 Gateway 后才获得这些读写工具；不承诺未接入的外部助手能够访问。

## 存储与一致性

记录保存于 `<stateDir>/memory/thoughts/thoughts.json`，随当前 Metis 数据目录持久化，与项目代码分离。文件使用现有私有原子写入工具（POSIX 文件 `0600`、目录 `0700`），没有数据库迁移。备份 Metis 数据时应包含该文件。当前版本不提供独立导出或历史版本恢复界面。

第一版使用有界 JSON 存储：每条正文最多 16 KiB UTF-8，最多 10,000 条有效记录，文件最大 32 MiB。读取和查询在服务端执行，客户端仅接收当前页。文件损坏时操作失败并保留现有文件，不以空数据覆盖。单后端拥有数据目录；直接从外部编辑文件不参与应用的并发控制。

创建使用调用方生成的稳定 ID，重试相同请求只保存一次。不同 ID 的相同正文可以代表不同时间的感受。编辑、删除必须提交刚读取的 revision，拒绝过期版本。删除会移除原文，只保留无正文的 ID 墓碑，防止迟到的创建重试恢复记录；最多保留 100,000 个墓碑。删除随想不会删除原对话中已存在的内容或已有外部备份。

## 接口

所有者 WebSocket API：`thoughts.list/read/create/update/delete`。沿用现有所有者校验，不向普通 client 会话开放。

| Agent 工具              | 输入                                          | 行为                                                             |
| ----------------------- | --------------------------------------------- | ---------------------------------------------------------------- |
| `metis_thoughts_list`   | `query?`, `from?`, `to?`, `offset?`, `limit?` | 关键词按正文子串匹配；按创建时间筛选；返回记录、总数、nextOffset |
| `metis_thoughts_read`   | `id`                                          | 读取原文、版本和来源                                             |
| `metis_thoughts_create` | `id`, `body`                                  | 新建或返回相同创建请求的结果；重试必须复用 ID                    |
| `metis_thoughts_update` | `id`, `body`, `expectedRevision`              | 更新正文，保留原始日期与创建来源                                 |
| `metis_thoughts_delete` | `id`, `expectedRevision`                      | 删除原文，不提供恢复                                             |

`from/to` 为包含边界的 ISO 时间；默认每页 20 条，最多 50 条。助手应继续查询 nextOffset，或明确说明仅回顾了当前页。查询是关键词匹配，暂不提供向量语义搜索。

读工具要求 `thread:read`，写工具要求 `thread:write` 且必须在活动轮次中调用。来源由服务端按调用上下文填写。Agent 写入复用现有凭据内容检测。写入失败不能回复“已记录”，修改冲突不能静默覆盖。

## 验证边界

使用临时目录测试持久化、中文检索、时间筛选、分页、重试去重、并发版本冲突、删除、损坏文件与工具来源。按仓库约定不运行前端测试或浏览器自动化；代码检查不能替代真实 Provider 和日常桌面的交互验收。
